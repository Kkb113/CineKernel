# Open decisions

1. Approve native wgpu as a Phase 1 candidate, not a final renderer, while retaining the deterministic native software reference and wrapped browser compatibility backends.
2. Select the production text shaping/raster stack and multilingual golden corpus; the Phase 0 bitmap font is evidence infrastructure only.
3. Define the five-to-ten-minute representative workload without turning `BenchmarkIntentSpec` into the future VideoIR.
4. Decide which media-parser functionality is adopted versus reimplemented, including the certified FFmpeg distribution/license boundary.
5. Define the initial certified GPU adapter/driver matrix and acceptable cross-driver pixel tolerances.

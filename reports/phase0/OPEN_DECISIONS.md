# Open decisions

1. Register and dispatch the manual benchmark workflow on the default branch; Phase 0.1 cannot claim an unconditional pass before the three-OS full/all run and Ubuntu network-isolation probe succeed.
2. Approve native wgpu as a Phase 1 candidate, not a final renderer, while retaining the deterministic native software reference and wrapped browser compatibility backends.
3. Select the production text shaping/raster stack and multilingual golden corpus; the Phase 0 bitmap font is evidence infrastructure only.
4. Define the five-to-ten-minute representative workload without turning `BenchmarkIntentSpec` into the future VideoIR.
5. Decide which media-parser functionality is adopted versus reimplemented, including the certified FFmpeg distribution/license boundary.
6. Define the initial certified GPU adapter/driver matrix and acceptable cross-driver pixel tolerances.

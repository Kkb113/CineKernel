# Skia feasibility probe

Phase 0 treats Skia as a bounded feasibility candidate. The implementation path
uses `tiny-skia`/`resvg` to keep the required cross-platform experiment reliable.
Exact Skia build attempts and results are recorded in
`reports/phase0/ARCHITECTURE_BAKEOFF.md`; lack of a successful local Skia build
is not evidence that Skia is unsuitable.
